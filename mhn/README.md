# MHN 装備計算（モンハンNow ダメージ期待値・装備構築）

公開URL: **https://nobuoiwase.github.io/Game3/mhn/**

モンハンNowのダメージ期待値を計算し、装備構成を探す個人用ツールです。

## 既存の計算サイトとの違い

- **結果が空になりません。** 弱い装備を固定しても、その構成の期待値と錬成の割り当てを必ず表示します。
  必須スキルを満たせないときも、不足分を表示したうえで下位に並べます。
- **錬成（漂移錬成）を防具ごとに設定できます。** 「フル錬成か錬成なし」の二択ではありません。
  - 自由（フル錬成）: 錬成で付くスキルから自由に選ぶ
  - 所持リストから: その防具が実際に持っている錬成スキルと個数だけを使う（例: 頭に弱点特効×2）
  - 固定: 実際にセットしている錬成スキルで計算する
  - 錬成なし
- **グレードを選べます。** 武器はグレード・段階（例: 8-3）、防具はグレードごとのスキル・錬成枠で計算します。
- 条件付きスキル（連撃・弱点特効など）の発動率を武器種ごとに変えられます。

## 画面

| タブ | できること |
| --- | --- |
| 装備構成検索 | 武器種・属性をアイコンで選び、武器（任意）・スタイル強化・必須スキル・クイック条件（ロックオン／集中／**錬成無し**／所持装備のみ）を指定して上位の構成を表示。**結果の防具をタップするとその場で錬成を編集して再計算**できます（防具の設定として保存も可） |
| 装備構成 | 武器・防具をアイコン付きの一覧から選んで期待値を表示。錬成欄をタップして編集。「固定」した部位以外を検索で埋められます |
| 所持・錬成 | 所持装備のグレードと、防具ごとの錬成（自由／所持リスト／固定／なし）を登録 |
| 設定 | 属性の扱い、発動率、自由錬成で付けられるスキル、バックアップ |

武器・防具・モンスターのアイコンは公式サイトの画像URLを表示時に参照しています（画像はリポジトリに含めていません）。

入力内容はブラウザの localStorage に保存されます（外部送信なし）。機種変更時は「設定 → バックアップ」で書き出してください。

## 計算式

モーション値100・肉質100あたりの期待値です（`js/calc.js`）。

```
物理 = floor((武器攻撃力 × (1 + 攻撃力%) + 攻撃力加算 + 追加攻撃力) × (1 + 攻撃活性%))
属性 = floor(floor((武器属性 × (1 + 属性%) + 属性加算) × (1 + 古龍属性%)) × 属性の扱い)
通常 = (物理 + 属性) × (1 + 与ダメージ%)
会心 = (物理 + 会心時の属性) × (1 + 与ダメージ%) × 会心倍率(1.25〜1.5)
期待値 = 通常 × (1 − 会心率) + 会心 × 会心率   （会心率が負なら 0.75 倍のマイナス会心）
```

- 攻撃力%（連撃・火事場力など）、与ダメージ%（闇討ち・不退転など）は同じ系統どうしで加算
- 条件付きスキルは「効果量 × 発動率」で按分
- 属性値は弱点属性の相手にだけ加算される前提（設定で 1.5 倍／加算しないに変更可）
- 錬成は 1枠 = スキル1Lv。枠数は防具のグレードで決まる
- 武器種ごとの固有補正は入れていないため、比較は同じ武器種どうしで行ってください

スキルがどの項に入るか・既定の発動率は `js/model.js` に一覧があります。
実機と合わない場合はここを直すか、設定タブの発動率で調整してください。

## データ

`data/*.json` は公式サイト（monsterhunternow.com/ja の武器・防具・スキル一覧）に
埋め込まれている数値データから生成しています（名前と数値のみ。画像や説明文は含めません）。

```bash
node mhn/tools/build_data.mjs   # 公式サイトから再取得して data/*.json を更新
npm test                        # mhn/test を含む全テスト
npm run serve                   # http://localhost:8360/mhn/
```

## 探索の仕組み（`js/search.js`）

1. 部位ごとに、他の防具に完全に劣る防具を除外（自由錬成の枠で埋められる差も考慮）。同性能の防具は1つにまとめ「同等」として表示
2. 組み合わせが多いときは各部位の有力候補で総当たりし、その後1部位ずつ全候補と入れ替える山登りで改善（近似。画面に表示）
3. 錬成は、必須スキルを先に満たし、残り枠を「1枠あたりの期待値の伸び」が最大のスキル×Lv数から順に割り当て
