# DBL フラグメント最適化アプリ

ドラゴンボールレジェンズ（DBL）で、**所持しているフラグメントをどのキャラにどう配分すれば
最終ステータスが最大になるか**を計算する個人用ツールです。
設計の全体像・計算式・データモデルは [DESIGN.md](./DESIGN.md) を参照してください。

- **全キャラ・全フラグメントのデータを収録**（参照サイトから半自動取得。画像は表示時にサイトを参照）
- Zアビリティ / ZENKAIアビリティ / 出撃Zアビリティ（LL） / フラグメントの補正を合算し、
  検証済みの計算式（DESIGN.md §2）で最終ステータス ❸ を算出
- Zアビ等のレベル（I〜IV）は限界突破の星から自動選択（キャラごとに上書き可）
- 装備可能なフラグメントの自動判定（参照サイトの解決済み対応表を使用）
- 所持数の奪い合いを含めて、パーティ全体で ❸（または重み付き総合値）が最大になる割当を探索
  （貪欲法＋分枝限定法。厳密解でない場合は「暫定解」と明示）
- ゲームの編成画面風UI: バトル3体＋ベンチ3体、キャラ／フラグメントのグリッド選択
- 未対応の効果文言は **黙って無視せず必ず警告表示**（DESIGN.md §1-4）
- 入力データはすべて端末内（IndexedDB）に保存。外部送信なし。個人利用前提

## 使い方

公開URL: **https://nobuoiwase.github.io/Game3/**

- **Android**: Chrome で開く → メニュー（⋮）→「アプリをインストール」（または「ホーム画面に追加」）
- **iPhone**: Safari で開く → 共有メニュー →「ホーム画面に追加」

### 画面の流れ

1. **編成タブ**: 「＋」枠をタップしてキャラを選ぶ（上段3体がバトル出撃）。
   未所持キャラを選ぶと自動で所持登録され、ブースト値はソウルブースト最大で初期化されます
2. **フラグタブ**: 所持しているフラグメントの個数を入力（タップ → ＋/−）
3. **編成タブの「最適化を実行」**: 最適な配分が装備枠に反映されます。
   装備枠を直接タップして手動で付け替えることもできます
4. **キャラタブ**: 星・装備枠・ブースト実測値・アビリティレベルを実機に合わせて調整
5. **データタブ**: バックアップのエクスポート／インポート（重要）

### 計算タブ（検証用）

実機のステータス画面と数値が一致するかを確認する画面です。検算(1)〜(3) ボタンで
DESIGN.md §2-4 の実機検証済みケースを再現できます。

## 開発

```bash
npm test          # 全テスト（§2-4 の検算ケース含む）
npm run serve     # http://localhost:8360
```

### ゲームデータの更新（半自動取り込み — DESIGN.md §5）

```bash
node tools/crawl_dblegends.mjs          # 新キャラ・新装備だけ差分取得（レジューム可能）
node tools/crawl_dblegends.mjs --merge  # 取得済みキャッシュから game_data/*.json を再生成
```

- 取得先は日本語版参照サイト（`game_data/config.json` の `asset_base`）。
  リクエスト間隔 2.5 秒・失敗ページは `game_data/crawl/failed/` に保存されます
- 生成物: `characters.json`（ステータス・タグ・アビリティ原文＋解析済み）、
  `fragments.json`（SLOT別効果・装備可能キャラID）、`tags.json`、
  `effect_lines_report.json`（効果語彙の頻度レポート）
- 新しい効果文言が警告されたら `game_data/effect_map.json` の `entries` に1行追加するだけで
  対応できます（コード変更不要）
- 利用は個人利用の範囲に留め、参照サイトに負荷をかけないこと。
  **画像はリポジトリに含めません**（公開リポジトリでのゲームアート再配布を避けるため、
  表示時にサイトのURLを参照します）

## 検証済み事項と仮定

- 計算式（❶〜❻）は実機数値で検算済み（`test/calc.test.mjs`）
- 実機未検証の仮定は DESIGN.md §10-2 に記録（星→アビリティレベル対応、
  同一フラグメントの重複装備不可、出撃Zアビの適用範囲など）。
  実機と数値がズレた場合はまずここを疑ってください
