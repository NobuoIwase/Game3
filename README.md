# DBL フラグメント最適化アプリ

ドラゴンボールレジェンズ（DBL）で、**所持しているフラグメントをどのキャラにどう配分すれば
最終ステータスが最大になるか**を計算する個人用ツールです。
設計の全体像・計算式・データモデルは [DESIGN.md](./DESIGN.md) を参照してください。

- Zアビリティ / ZENKAIアビリティ / LLアビリティ / フラグメントの補正を合算し、
  検証済みの計算式（DESIGN.md §2）で最終ステータス ❸ を算出
- キャラのタグとフラグメントの装備条件から装備可能なものを自動選出
- 所持数の奪い合いを含めて、パーティ全体で ❸（または重み付き総合値）が最大になる割当を探索
  （貪欲法＋分枝限定法。厳密解でない場合は「暫定解」と明示）
- 未対応の効果文言は **黙って無視せず必ず警告表示**（DESIGN.md §1-4）
- データはすべて端末内（IndexedDB）に保存。外部送信なし。個人利用前提

## 使い方

### ローカルで開く

```bash
npm run serve   # http://localhost:8360
```

初回は「データ」タブ →「サンプルを読み込む」で動作確認できます。
その後「キャラ」「フラグ」タブで実機の数値を入力してください。

### テスト

```bash
npm test
```

DESIGN.md §2-4 の検算ケース（❸ が小数第2位まで一致）を含む全テストが実行されます。
**実装を変更したら必ずここが通ることを確認してください。**

### スマホにインストールする（PWA）

公開URL: **https://nobuoiwase.github.io/Game3/**

`main` ブランチに push すると GitHub Actions がテストを実行し、成功したら
main の内容を `gh-pages` ブランチへミラーして公開します（Pages のソースは gh-pages ブランチ）。
※無料プランの GitHub Pages はリポジトリが Public のときだけ使えます。

- **Android**: Chrome で上のURLを開く → メニュー（⋮）→「アプリをインストール」
  （表示によっては「ホーム画面に追加」）。以後はアイコンからアプリとして起動できます
- **iPhone**: Safari で開く → 共有メニュー →「ホーム画面に追加」

一度開けば Service Worker がキャッシュするため、オフラインでも動作します。

## 画面の構成

| タブ | 内容 |
|---|---|
| 計算 | 1キャラ分の ❶〜❻ を計算（v0 検証用）。検算(1)〜(3) ボタンで実機検証済みケースを再現 |
| 最適化 | パーティ6体（上3体がバトル出撃）を選び、最適なフラグメント割当を計算 |
| キャラ | キャラの登録、合計ステ・ブースト値・星・装備枠・アビリティの入力 |
| フラグ | フラグメントの定義と所持数の入力 |
| データ | エクスポート/インポート（重要）、サンプル、HTML貼り付け取り込み、効果変換表 |

## データの持ち方

- `game_data/` … 外部由来（キャラ・フラグメント定義、効果変換表）。消して再取得してよい
- `my_data/` … サンプルのみ。**実データはブラウザの IndexedDB** に保存され、
  「データ」タブからエクスポート/インポートできます。**復旧不能なので定期的にエクスポートしてください**
- アプリ内での編集はオーバーライドとして保存され、`game_data` の再取得で消えません

### 新しい効果文言への対応

未対応の効果が警告されたら、`game_data/effect_map.json` の `entries` に1行追加するだけです（コード変更不要）:

```json
"基礎○○アップ": { "stat": "対応する内部キー", "base": true }
```

### データ取り込み

- アプリ内「データ」タブの **HTML貼り付け取り込み**（端末単独で完結）
- または `tools/config.example.json` を `tools/config.json` にコピーして
  `node tools/update_data.mjs`（取得した生HTMLは `game_data/snapshots/` に日付付きで保存されます）

いずれも参照サイトの利用規約に従い、個人利用の範囲でリクエスト間隔を空けて使ってください。
ゲーム本体からのデータ抽出（データマイニング）は行いません。

## 開発メモ

- 依存パッケージなし。`js/calc.js`（計算式）と `js/optimizer.js`（最適化）は純粋関数で、
  Node からもブラウザからも同じものが使われます
- アイコン再生成: `node tools/gen_icons.mjs`
- 実装時の決定事項・未検証の仮定は DESIGN.md §10 に記録しています
